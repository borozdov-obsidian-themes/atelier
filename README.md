# Borozdov Atelier

A theme from the Borozdov collection. Two faces — light **Oatmeal**, a warm atelier under
soft daylight, and dark **Umber**, the same studio after the lamps come on. Cream paper,
charcoal text, a hairline serif headline, pill buttons and one sage for links.

![Borozdov Atelier in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/atelier/main/screenshots/light.png)

![Borozdov Atelier in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/atelier/main/screenshots/dark.png)

## Principles

- **Skin and ceramic.** Cream-oatmeal paper, never pure white; bone cards one tone above
  it; soft charcoal text. Nothing casts a shadow — surfaces differ by tone and a stone
  hairline.
- **Airy display, breathable body.** Atelier Serif ExtraLight, a hairline serif, for the
  title, the two largest headings and pull quotes, set tight and tracked in; the
  platform's own sans, at 400 for the text and 500 for labels, with small labels tracked
  open.
- **One onyx pill.** The main button, a checked task and a toggle are near-black; sage,
  the only tint, carries links and the caret.
- **Pills and small corners.** Buttons and tags are pills; cards, code and tables keep
  8px corners, fields 12px.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Pull quotes in the hairline serif, two sizes up, with no rule
- Callouts as bone cards with a stone edge and the title in the type's colour
- Tags and property values as ghost pills with a stone rim
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory, as a variant:** this theme ships inside **Borozdov
Trellis**. Install Borozdov Trellis under Settings → Appearance → Themes → Manage, then
the [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin, and
choose **Atelier** under Style Settings → Borozdov Trellis → Variant. The variant brings
this theme's palette, type and corners; its own layout, and its embedded font if it has
one, come with the full theme below.

**The full theme, by hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/atelier/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Atelier/`, then choose Borozdov Atelier under
Settings → Appearance → Themes.

## Font

Atelier Serif is embedded in `theme.css` as base64 WOFF2 under the SIL Open Font License
1.1 — see [`fonts/OFL.txt`](fonts/OFL.txt). It is a Latin and Cyrillic subset of IBM Plex
Serif ExtraLight (© 2020 IBM Corp.), renamed because a modified copy may not use the
original's Reserved Font Name. One weight, for the title, the two largest headings and
pull quotes only.
